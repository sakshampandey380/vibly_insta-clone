# Vibly

Vibly is a phase-1 Instagram-like social media application with a dreamy glassmorphism UI, public feed browsing, auth-gated actions, and a MySQL-ready Express API.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Node.js + Express
- MySQL schema and seed files
- JWT auth + bcrypt + multer-ready upload structure

## Run

1. Install dependencies with `npm install`
2. Copy `client/.env.example` to `client/.env`
3. Copy `server/.env.example` to `server/.env`
4. Start both apps with `npm run dev`

The frontend is demo-data friendly by default, so the UI works before MySQL is configured.
